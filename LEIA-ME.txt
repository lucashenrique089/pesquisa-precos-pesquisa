MONITOR DE PREÇOS DA CONCORRÊNCIA | Roma Pneus
===============================================

ARQUIVOS
- app.py                    -> painel no Streamlit (abas: Mais vendidos, Mais pesquisados, Histórico, Promoções)
- coletor.py                -> busca os preços na Roma, Pneu Store e Achei Pneus e detecta promoções
- produtos_monitorados.csv  -> lista dos 14 pneus, links e preço cheio da Roma (edite aqui)
- requirements.txt          -> bibliotecas necessárias
- .streamlit/config.toml    -> tema claro com texto preto (manter a pasta .streamlit com o ponto)

PRIMEIRA VEZ (no terminal do VS Code, dentro da pasta)
  python -m pip install -r requirements.txt

ATUALIZAR OS PREÇOS
  Rodar o coletor.py (botão ▶️ no VS Code) ou clicar em "Atualizar preços" no app.
  São criados/atualizados:
    base_concorrencia.xlsx    -> foto atual (o app lê este arquivo)
    historico_precos.csv      -> todas as coletas
    historico_promocoes.csv   -> promoções e mudanças de preço detectadas

ABRIR O APP NO COMPUTADOR
  python -m streamlit run app.py

STREAMLIT CLOUD
  Subir no GitHub todos os arquivos acima, incluindo os três gerados pelo coletor,
  para o app na nuvem mostrar os dados e manter o histórico.
